## Lecture

Un passage introuvable vient le plus souvent d'un ordre de lecture différent (colonnes, encadrés, notes) : il chevauche alors deux blocs que l'autre bibliothèque lit séparément. Un passage trouvé à une autre page signale une erreur de page. Ce test mesure l'accord entre bibliothèques, pas encore les citations du modèle : il sera repris avec les citations de l'IA au tri du texte intégral (tranche 2.2).
